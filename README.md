# Form App

Reactで作成したお問い合わせフォームアプリです。  
バリデーションや送信状態を実装し、入力内容を確認・管理できます。

## 使用技術
- React (Create React App)
- JavaScript
- MUI (Material UI)
- Yup
- React Hook Form

## 機能
- 入力フォーム（お名前・メールアドレス・件名・本文）
- Yupによるバリデーション
- React Hook Formによるフォーム管理
- 送信処理（擬似送信を実装済）
- プライバシーポリシー同意チェック必須
- 送信完了メッセージ表示
- **レスポンシブデザイン対応（PC/スマートフォン）**
